# Dutch Game - Règles du jeu

## 🎯 Objectif

Terminer la manche avec le **moins de points possible** en gérant intelligemment vos 4 cartes cachées.

## 🎮 Configuration

- **Joueurs** : 2 à 4 (humain + bots)
- **Deck** : 52 cartes standard + 2 Jokers = 54 cartes
- **Cartes par joueur** : 4 cartes face cachée

## 🔄 Déroulement

### Phase de mémorisation
1. Chaque joueur reçoit 4 cartes face cachée
2. Vous pouvez regarder 2 cartes de votre choix (une seule fois)
3. Une carte de départ est placée dans la défausse

### Tour de jeu

À votre tour, **2 choix possibles** :

**1️⃣ Piocher une carte**
- Regarder la carte piochée
- **Option A** : Échanger avec une de vos cartes (la carte remplacée va dans la défausse)
- **Option B** : Défausser directement la carte piochée
- Si la carte défaussée a un pouvoir, vous pouvez l'activer
- ⚠️ **Si vous piochez, vous ne pouvez PLUS annoncer Dutch ce tour**

**2️⃣ Annoncer "DUTCH"**
- Uniquement si vous n'avez pas pioché
- Termine la manche immédiatement
- Tous les joueurs révèlent leurs cartes
- ✅ Si vous avez le plus petit score → vous gagnez
- ❌ Sinon → vous êtes dernier

### ♻️ Défausse collective (après chaque carte défaussée)

- Tous les joueurs peuvent défausser une carte **strictement identique** (même valeur)
- Les Rois : seuls les Rois rouges (♥ ♦) matchent entre eux, et les Rois noirs (♠ ♣) entre eux
- ⚠️ **Mauvaise carte** → vous la reprenez + carte de pénalité
- Temps de réaction : quelques secondes

|-------|--------|

| 👑 Roi rouge (♥ ♦) | 0 |
| As | 1 |
| 2 à 10 | Valeur faciale |
| 🤵 Valet | 11 |

| 👑 Roi noir (♠ ♣) | 13 |

## ✨ Cartes spéciales (Pouvoirs)

Les pouvoirs s'activent **uniquement quand la carte est défaussée**.

### 7️⃣ Le Sept
- Regardez une de vos cartes cachées

### 🔟 Le Dix
- Regardez une carte d'un adversaire

### 🤵 Le Valet
- Échangez une carte :
  - Soit entre vous et un adversaire
  - Soit entre deux adversaires

### 🃏 Le Joker
- Mélangez la main d'un joueur (y compris vous-même)
- Le joueur ciblé oublie toutes ses cartes

## 🎮 Modes de jeu

### ⚡ Partie rapide
- Une seule manche
- Le joueur avec le moins de points gagne

### 🏆 Tournoi
- Plusieurs manches
- Les scores s'accumulent
- Élimination à 100 points
- Le dernier joueur restant gagne

## 🤖 Niveaux de difficulté des bots

### 🥉 Bronze (0-299 RP)
- Oublient souvent (25%/tour)
- Erreurs fréquentes (45%)
- Dutch à 12 points ou moins
- Réaction lente

### 🥈 Argent (300-599 RP)
- Bonne mémoire (oubli 10%/tour)
- Peu d'erreurs (15%)
- Dutch à 6 points ou moins
- Réaction correcte

### 🥇 Or (600-899 RP)
- Excellente mémoire (oubli 2%/tour)
- Très précis (erreur 5%)
- Dutch à 4 points
- Réaction rapide

### 💎 Platine (900+ RP)
- Mémoire PARFAITE (jamais d'oubli)
- AUCUNE erreur
- Dutch ultra-agressif à 2 points
- Réaction instantanée (95%)

## 🎯 Stratégies

### Débutant
- Mémorisez bien vos 2 cartes initiales
- Échangez vos cartes fortes (Dame, Roi noir)
- Utilisez les pouvoirs 7 et 10 pour obtenir des infos
- N'annoncez Dutch que si vous êtes sûr d'avoir le meilleur score

### Avancé
- Mémorisez les cartes défaussées
- Anticipez les cartes des adversaires
- Utilisez le Valet stratégiquement (échange entre adversaires)
- Bluffez avec le Joker (mélangez un adversaire qui a peu de cartes)
- Annoncez Dutch au bon moment (pas trop tôt, pas trop tard)

### Expert
- Comptez les cartes restantes dans la pioche
- Calculez les probabilités de piocher une bonne carte
- Utilisez la défausse collective pour vous débarrasser de cartes rapidement
- Gérez votre timing pour maximiser vos RP
